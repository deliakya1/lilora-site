観葉植物の挿し木：水で発根させるか、用土に挿すか

健康な節を含む茎の挿し穂を取り、水や挿し木用土で発根させる方法。それぞれの利点・欠点と、鉢に植える手順を紹介します。

要点

節（葉が茎に付く部分）がいくつかある健康な茎の先端を選び、節のすぐ下で切って、下の方の葉を取り除きます。つる性や垂れ下がる観葉植物の多くは、コップの水で発根します。一方、湿り気があり通気性のよい挿し木用土に向くものもあります。水では根の様子が見やすく、用土では鉢に移した後になじみやすい根が育つことがよくあります。植物が成長する春から初夏が、最も取り組みやすい時期です。バーモント大学エクステンション：観葉植物を増やす

挿し穂に必要なもの

挿し木でできる株は、親株と同じ性質を持ちます。新しい根は通常、節から出るため、少なくとも一つの節と、エネルギーを作るための数枚の葉が必要です。バーモント大学は、節を葉と茎が接するふくらみと説明し、節をいくつか含む長さ約8〜15cmの先端を挿し穂にするよう勧めています。バーモント大学エクステンション：観葉植物を増やす

害虫がいない、しっかりした健康な部分を選びます。茎の挿し木は、比較的新しい成長部分から取ると発根しやすくなります。ミズーリ植物園：室内植物を増やす

どの観葉植物も茎の挿し木で増やせるわけではありません。ストレプトカーパス（Streptocarpus）、サンスベリア（Sansevieria）、一部のペペロミアは葉挿しで増やせ、多肉植物の中には葉1枚から発根するものもあります。RHS：葉挿し 株分けや子株で増やす種類もあります。切る前に、その植物に合う方法を確認しましょう。

茎の挿し穂の取り方

  1. 茎がしおれないように、前日に親株へ水を与えます。
  2. 節のすぐ下で、長さ約8〜15cmの先端を切ります。
  3. 下側の一つか二つの節にある葉を取り除きます。
  4. 以下の説明に沿って、水か挿し木用土で発根させます。
  5. 植物名と日付をラベルに書きます。

ネバダ大学リノ校エクステンションも、フィロデンドロンやホヤなどの柔らかい茎の植物に同じ基本手順を紹介し、発根促進剤の粉末は任意としています。ネバダ大学リノ校エクステンション 発根促進剤を使う場合は、製品の表示に従ってください。

水で発根させる

清潔なコップや瓶に挿し穂を入れ、葉を取った節が水につかり、葉は水面より上に出るようにします。強く暑い直射日光を避け、明るい場所に置きます。定期的に水を替え、濁りやぬめりが出たら容器を洗います。

水での発根は、ポトス（Epipremnum）、ヒメカズラ、トラデスカンチアなど、多くのつる性・下垂性植物に向いています。利点は、根が育つ様子を見られることです。一方、水中で育った根は水に適応しているため、鉢へ移した際になじみにくいことがあります。ミズーリ植物園：室内植物を増やす

根が大きく絡まるまで待たず、数cm伸びたら鉢に植えます。根がなじむ最初の数週間は、新しい鉢の用土に軽い湿り気を保ちます。

発根後のポトスの管理は、ポトスの植物紹介をご覧ください。

用土で発根させる

パーライト、バーミキュライト、または培養土にパーライトを混ぜたものなど、軽く水はけのよい挿し木用の培地を使います。ミズーリ植物園は、このような配合が一般的な培養土だけの場合より適しているとしています。ミズーリ植物園：室内植物を増やす

  1. 用土を湿らせ、排水穴のある小さな鉢に入れます。
  2. 鉛筆などで穴を作り、葉を取った節が隠れる深さに挿し穂を入れます。
  3. 茎の周りの用土を軽く押さえます。
  4. 湿度を保つため透明な袋や蓋で緩く覆い、ときどき空気を入れ替えます。
  5. 数週間後、軽く引いたときに抵抗があれば、根ができています。

多肉植物は、切り口を数日乾かしてから粒の粗い用土に挿し、乾かし気味に管理します。

RHSの繁殖に関するページには、種類によって使う、古い茎の一部を付けて取るヒール挿しなど、いくつかの方法が説明されています。RHS：植物を増やす技法

その後の管理

鉢に植えたら、若い株もほかの植物と同じように扱います。水やりの前に用土を確認し、適した光を与え、成長が始まってから肥料を使います。日数を固定しない水やり、室内の光、用土と排水で基本を紹介し、植え替えの時期で次に大きな鉢へ移す目安を説明しています。

根腐れした植物でも、健康な茎が残っていれば、挿し木で一部を救えることがあります。観葉植物の根腐れを参照してください。

よくある質問

発根にはどのくらいかかりますか？

植物、明るさ、暖かさによって異なり、2週間ほどから1か月以上かかることもあります。待つことも、この方法の一部です。

ポトスやモンステラは葉1枚だけで増やせますか？

節のない葉は、通常、新しい株にはなりません。節を含めて切り取ってください。

挿し穂が腐ったのはなぜですか？

水中に葉が入っていた、水が古くなった、健康な節がなかった、用土が湿りすぎた、といったことがよくある原因です。

挿し穂を友人に分けてもよいですか？

はい。ただし、渡す前に親株と挿し穂に害虫がいないか確認してください。国境を越えて持ち運ぶ場合は、関係する国の規則を守りましょう。
