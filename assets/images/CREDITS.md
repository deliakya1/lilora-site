# Website image credits

These seven original illustrative scenes were generated with the built-in OpenAI `image_gen` tool on 20 October 2026. One attempt was used for each image (seven images in total). No paid API fallback was used. They are not customer photographs, diagnostic specimens or app screenshots. Text is rendered separately in HTML, SVG or Playwright.

Each image was visually reviewed for coherent leaves, stems, pots and scene content. Named-plant care advice does not rely on these illustrations. WebP variants are proportional resizes, with dimensions and SHA-256 hashes in `home/illustrations.json`.
