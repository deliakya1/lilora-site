室內植物爛根：跡象、原因與處理

簡要回答

爛根是根系腐敗，通常發生在介質過濕太久之後。介質濕潤卻萎蔫是典型警訊，但要看根才能確認：健康根堅實、通常淡色，腐根則柔軟、褐色、糊爛。若還有健康根，剪除腐爛部分，換新介質並謹慎澆水。Iowa State University Extension: root rots of houseplants

什麼造成爛根

多種真菌與類真菌生物會造成爛根，包括 Pythium、Phytophthora、Rhizoctonia 和 Fusarium。通常在植物受壓後侵入，最常見壓力是過度澆水或排水差。Iowa State University Extension: root rots of houseplants

Pythium 可經水傳播，孢子能沿水膜游向根，所以持續濕介質、髒盆與工具都重要。Utah State University Extension: Pythium root rot

光是積水也會傷根，症狀相近。RHS 指出，Phytophthora 主要在黏重或積水環境造成問題。家庭種植者無法肉眼區分，也不需要：初步處理相同。RHS: Phytophthora root rot

土面以上的跡象

  • 介質仍濕卻萎蔫，常先從下葉開始。
  • 黃葉、生長變慢。
  • 莖基部變深或變軟。
  • 介質濕好幾天，可能有酸味。

University of Maryland Extension 描述，即使介質水分足夠仍會矮化、黃化、萎蔫。這些與缺水、寒冷、害蟲重疊，不能只看葉就診斷。University of Maryland Extension: root rots of indoor plants 先用水太多還是太少？檢查。

如何看根

健康根通常堅實、白或淡色，常有許多細吸收根。腐根則糊爛，褐色或帶紅。Iowa State University Extension: root rots of houseplants 嚴重時輕拉就讓外層滑脫，只剩細絲，許多根會留在盆裡。University of Maryland Extension: root rots of indoor plants

發現腐爛後怎麼做

  1. 在報紙上操作，移除根周圍舊濕介質。
  2. 用乾淨剪刀把軟褐根剪到堅實組織。
  3. 選乾淨有孔盆，尺寸只需容納剩餘根；太大會保留更多濕介質。
  4. 用新室內植物介質，維持原深度，不重用舊土。Clemson Cooperative Extension: repotting indoor plants
  5. 先少量澆一次使介質沉實，瀝乾後等乾到合適程度再澆。
  6. 放良好間接光、避冷風，新生長出現前不施肥。
  7. 舊盆和工具清洗後才能再用。Utah State University Extension: Pythium root rot

幾乎所有根都爛時，很難恢復，連介質丟棄通常是實際選擇。若莖仍有健康堅實部分，插穗可能長成新株，詳見扦插繁殖。

本文不建議殺菌劑療程。各國產品與核准不同；若考慮使用，只選標示適用室內植物的產品並完全依標籤。

下次如何預防

  • 介質需要才澆，不按日曆。澆水指南說明檢查。
  • 用有孔盆，澆後倒空托盤與外盆。
  • 選適合物種、排水好的介質，詳見介質與排水。
  • 預期冬光和涼房乾得慢。
  • 根需要時只換稍大盆，詳見何時換盆。

記每次檢查很有幫助。Lilora 分開儲存 “Checked, no water needed”（已檢查，不需澆水）和 “Watered”（已澆水），所以濕了十天的盆會呈現連串檢查，不會被記憶漏掉。

常見問答

爛根會傳其他植物嗎？

病原可經水、介質與工具移動。受害株用獨立托盤，盆與工具再用前清洗。Utah State University Extension: Pythium root rot

要把根團攤在空氣中乾燥嗎？

不要讓根裸露太久。修剪、換新介質，再控制水分。

萎蔫但根正常，接下來呢？

爛根就不太可能。查光、溫度、害蟲與近期變化，詳見黃葉指南。

雙氧水是好處理方式嗎？

我們未找到有安全家庭用量的機構指引，因此不推薦劑量。
