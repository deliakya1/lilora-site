# 橡膠樹照護

橡膠樹是原產東喜馬拉雅山區至馬來西亞植物區系西部的榕屬植物，常因厚實亮澤的葉片而在室內栽培。提供明亮間接光，兩次澆水間讓介質稍乾，保持約 13 °C（55 °F）以上並避開冷風。修剪時要戴手套，避免接觸白色汁液。ASPCA 將俗名 <span lang="en">“Indian rubber plant”</span> 的植物列為對貓狗有毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-elastica/)

## 光線

在室內喜歡明亮間接光，應避免強烈午後日照。斑葉與深色葉品種仍需良好光線；斑葉比全綠葉需要更多光。低光會使莖拉長、下葉掉落。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-elastica/) · [RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)說明如何評估窗邊位置。

## 澆水前如何檢查

春夏規律檢查並澆水，兩次之間讓介質稍乾。秋季到冬末生長變慢時，只維持微濕。過度澆水是榕屬落葉最常見的原因，因此每次澆水前都要檢查表面以下的狀態。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-elastica/) · [RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

詳見[澆水指南](/zh-hant/guides/watering-houseplants/)。

## 介質與花盆

NC State 建議以土壤為基礎、排水良好的盆栽介質。橡膠樹可長得很高，較重的盆能保持穩定。幼株根系擁擠時，在春季換盆。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-elastica/)

## 濕度與溫度

需保持 13 °C（55 °F）以上，寒冷或冷風吹拂時表現不佳。中等濕度合適；擦掉葉上灰塵可讓葉片接收到更多光。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-elastica/)

## 施肥

春季到夏末依標籤用量施高氮肥，冬季停肥。[RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

## 常見問題

- **落葉：**過度澆水、溫度突然下降或冷風。NC State 指出，少量底葉脫落屬正常。
- **蟲害：**粉介殼蟲、介殼蟲與葉蟎。
- **莖徒長：**光線不足；可在冬末或早春於葉片上方修剪。

[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)協助分辨正常老化與問題。

## 繁殖

春季或夏末適合用高壓法繁殖；RHS 指出，生根可能需要約一年。也可以使用半成熟枝條扦插。[RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將 <span lang="en">“Indian rubber plant”</span> 列為對貓狗有毒；該條目的學名是 *Ficus benjamina*，列出的毒性成分為蛋白分解酶 ficin 與補骨脂素 psoralen（ficusin），未列症狀。NC State Extension 亦將 *Ficus elastica* 標示為對貓狗有風險，RHS 則提醒榕屬汁液會刺激皮膚。若寵物咬食，請聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。

## 常見問答

### 新葉上的紅色外鞘是什麼？

那是保護新葉的托葉，葉片展開後會乾燥脫落。

### 如何讓橡膠樹更茂密？

冬末或早春在葉片上方修剪，切口下方常會長出新芽。

### 白色汁液危險嗎？

可能刺激皮膚。請戴手套，避免接觸寵物與家具。
