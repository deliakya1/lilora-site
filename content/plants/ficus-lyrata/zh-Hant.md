# 琴葉榕照護

琴葉榕原產西非與中非，在室內以大型小提琴形葉片受到喜愛。它需要明亮間接光、穩定溫暖且無冷風的環境，也對過度澆水敏感，應謹慎管理水分。盡量少搬動。寵物安全資料並不一致，因此應把它放在寵物碰不到的地方。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-lyrata/)

## 光線

喜歡明亮間接光，避開強烈午後日照較好。RHS 指出，有些榕屬能忍受幾小時的早晨或傍晚陽光，尤其在冬季。光線不足會使生長變慢、落葉；突然搬到炎熱陽光下會曬傷。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-lyrata/) · [RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

詳見[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)。

## 澆水前如何檢查

春夏在介質稍乾後使用室溫水澆灌，冬季只維持微濕。NC State 說明它對過度澆水敏感，RHS 也將過度澆水列為榕屬落葉最常見的原因。往下檢查幾公分，可以的話也提盆確認重量。[RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

[澆水指南](/zh-hant/guides/watering-houseplants/)說明濕度檢查方式。

## 介質與花盆

使用兼具保水與良好排水的介質，以及有排水孔的重盆。幼株根系填滿花盆時，於春季換盆；大型植株更換表層介質可能比較方便。

## 濕度與溫度

保持 13 °C（55 °F）以上；RHS 給出的最低範圍為 10–13 °C（50–55 °F）。避開冷風與劇烈變化。NC State 指出，出風口附近的溫度波動可能造成褐斑。中至高濕度合適。[NC State Extension](https://plants.ces.ncsu.edu/plants/ficus-lyrata/) · [RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

## 施肥

RHS 建議春季到夏末依標籤用量施高氮肥。冬季或根系受損時不施肥。[RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

## 常見問題

- **落葉：**過度澆水、寒冷、冷風、低光或過量施肥。先回想最早發生了什麼變化。
- **曬傷斑塊：**直射日光過強。
- **褐斑：**出風口附近溫度波動或水分過多，請檢查根系。
- **蟲害：**介殼蟲、蚜蟲、粉介殼蟲、薊馬與葉蟎。

採取行動前請使用[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)。

## 繁殖

春季或夏季取半成熟莖段扦插。請戴手套：黏稠的白色汁液可能刺激皮膚。[RHS](https://www.rhs.org.uk/plants/ornamental-figs/growing-guide)

## 寵物與人

資料來源並不一致。[ASPCA Animal Poison Control Center](https://www.aspca.org/) 的植物資料庫沒有以 *Ficus lyrata* 學名列出琴葉榕，雖然將其他榕屬列為有毒。ASPCA 的一篇室內植物文章把琴葉榕列入可能造成輕微腸胃不適的植物，並提到汁液可能刺激皮膚。NC State Extension 則列為對貓狗有毒。請放在寵物碰不到的地方。若寵物咬食，聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。

## 常見問答

### 為什麼琴葉榕落葉？

常見誘因是過度澆水、冷風、低光與搬動植株。先檢查介質。

### 夏季可以放戶外嗎？

只能放在溫暖、避風、避開烈日的位置，夜間變涼之前要搬回室內。

### 應該擦葉片嗎？

灰塵會減少受光。用濕布輕輕擦拭，同時托住每片葉子。
