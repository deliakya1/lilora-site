# 黃金葛照護

黃金葛是原產社會群島的蔓性天南星科植物，能適應許多居家環境。提供明亮的間接光，澆水前檢查介質，並讓多餘的水流走。它耐較低光線，但生長會變慢，斑葉也可能變得更綠。ASPCA 將它列為對貓狗有毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/epipremnum-aureum/)

## 光線

黃金葛最適合明亮的間接光，也就是光線充足、日光不會連續數小時照在葉上的位置。它可在低光環境存活很久，所以常見於辦公室。放在暗角時，葉片可能變小、節間變長，黃色或白色斑紋減少。[NC State Extension](https://plants.ces.ncsu.edu/plants/epipremnum-aureum/)

若斑葉逐漸變成全綠，移近窗戶一點，觀察接下來幾片新葉。[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)說明如何觀察一天中的光線變化。

## 澆水前如何檢查

黃金葛需要排水良好、在兩次澆水之間能乾燥的介質。將手指伸入介質：上方幾公分摸起來乾，花盆也比上次澆水後明顯變輕時，緩慢澆到水從排水孔流出，再倒空托盤。若仍涼涼濕濕的，就等幾天再檢查。[NC State Extension](https://plants.ces.ncsu.edu/plants/epipremnum-aureum/)

提醒是請你觀察，不是植物口渴的證明。[澆水指南](/zh-hant/guides/watering-houseplants/)介紹花盆重量及其他線索。

## 介質與花盆

使用一般排水良好的室內植物介質與有孔花盆。可以放在裝飾外盆中，但要取出內盆瀝水。黃金葛不需要大容器；根繞圈且介質異常快乾時，再升一個尺寸。

## 濕度與溫度

一般室內空氣通常就足夠。房間因供暖而非常乾燥時，NC State Extension 建議用加濕器或濕卵石托盤提高周圍濕度。黃金葛是熱帶攀爬植物，冬季應放在溫暖房間，遠離冷窗與冷風。[NC State Extension](https://plants.ces.ncsu.edu/plants/epipremnum-aureum/)

## 施肥

積極生長時約每隔一個月施一次室內植物肥，依標籤用量。冬季生長減慢時不施肥。[NC State Extension](https://plants.ces.ncsu.edu/plants/epipremnum-aureum/)

## 季節照護

NC State 將冬季視為休眠期：停肥至春季，並繼續讓排水良好的介質在澆水之間乾燥。生長減慢後，乾燥需要更久，澆水間隔因此變長。NC State 指出，過度澆水與爛根、葉緣變黑有關；把夏季習慣沿用到昏暗冬季，更容易遇到這些問題。[NC State Extension](https://plants.ces.ncsu.edu/plants/epipremnum-aureum/)

黃金葛能在低光下存活很久，但 NC State 指出低光會讓斑紋褪去；較暗月份移近窗戶有幫助。[冬季照護指南](/zh-hant/guides/winter-houseplant-care/)說明冷玻璃與暖氣的影響。在 Lilora，提醒是請你檢查，並非命令澆水；可分別記錄「已檢查，不需澆水」或「已澆水」，讓寒冷月份較慢的乾燥速度反映在歷史紀錄中。延後提醒只會推遲提醒，不會新增照護紀錄。

## 常見問題

- **葉緣發黑、莖變軟：**NC State 將這些現象與過度澆水和爛根連結。加水前先檢查介質與根系。
- **斑紋消失：**通常是光線不足。
- **蟲害：**檢查莖和葉背是否有粉介殼蟲、介殼蟲及薊馬。

一片黃葉不能指出原因。同時改變多件事之前，先依[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)逐步排查。

## 繁殖

黃金葛的莖插很容易生根。剪取至少帶一個節點的莖段，也就是葉片與氣生根相接的凸點，放入水中或濕潤介質，新根出現後再上盆。NC State 指出，蔓莖很容易在水中生根。[NC State Extension](https://plants.ces.ncsu.edu/plants/epipremnum-aureum/)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將黃金葛列為對貓狗有毒。NC State Extension 指出毒性來自草酸鈣結晶，症狀包括口腔刺激與腫脹、流口水、吞嚥困難和嘔吐；汁液也可能刺激皮膚。請把下垂枝條放在寵物碰不到的地方。若寵物咬食，聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。比較其他植物可看[植物與寵物指南](/zh-hant/guides/pet-safe-houseplants/)或[無毒植物圖鑑](/zh-hant/plants/#petNonToxic)。

## 常見問答

### 黃金葛可以住在沒有窗戶的房間嗎？

必須有足夠的人造光。低光仍然需要光，無窗房間需要合適的植物燈。

### 為什麼新葉變小？

光線不足是常見原因。施肥或換盆之前，先檢查位置。

### 要替黃金葛噴霧嗎？

不需要。空氣非常乾燥時，NC State 提到的選項是加濕器或卵石托盤。

### 為什麼葉緣變黑？

NC State 將葉緣發黑與過度澆水及爛根連結。再次澆水前先檢查介質和根。
