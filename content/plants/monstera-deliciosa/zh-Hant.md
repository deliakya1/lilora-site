# 龜背芋照護

龜背芋是原產墨西哥至巴拿馬的攀爬性天南星科植物。在室內需要中至明亮光線，避開炎熱直射日光；使用肥沃排水介質，讓上方約三分之一乾燥再澆水，並提供溫暖及一定濕度。較大的植株需要攀爬支撐。ASPCA 列為對貓狗有毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/)

## 光線

NC State Extension 指出，龜背芋喜歡中等亮度而非直射日光。離東窗或西窗稍遠的位置，或日光不會停留在葉上的明亮房間，通常合適。斑葉品種比全綠品種需要更多光。[NC State Extension](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/)

成熟植株葉片沒有裂口，或長長的裸莖傾向窗戶，都可能是光線不足。[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)說明如何觀察位置。

## 澆水前如何檢查

澆透後，等介質上方約四分之一至三分之一乾燥再澆。若盆深 20 公分，就要檢查數公分深處，而非只看表面。輕插木籤有助判斷；若沾著濕潤顆粒，就繼續等。[NC State Extension](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/)

澆水後讓多餘水分流走，並倒空外盆。[澆水指南](/zh-hant/guides/watering-houseplants/)解釋為何檢查比固定日程更可靠。

## 介質與花盆

使用富含有機質且排水良好的介質與有孔容器。龜背芋可以長很大；根擁擠時在春季換盆，只小幅增加尺寸。加上水苔柱或牢固支柱：它在自然環境會攀爬，有支撐的莖往往長出更大的葉。

## 濕度與溫度

偏好約 16–29 °C（60–85 °F）的溫暖環境與高濕度。乾燥住宅可依 NC State 建議使用加濕器或卵石托盤。避開冷風與暖氣。[NC State Extension](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/)

## 施肥

春夏依標籤用量施均衡室內植物肥，冬季停肥。正在萎蔫或根系濕透受損的植株不應施肥。

## 季節照護

NC State 沒有另列冬季日程，因此持續採用相同檢查：澆透後，等上方約四分之一至三分之一乾燥。日照變短、房間較涼時通常乾得較慢，檢查間隔也會拉長。保持在偏好的 16–29 °C（60–85 °F），避開冷玻璃和暖氣熱風。依 NC State 建議，修剪與換盆留到春季。[NC State Extension](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/)

夏季向陽窗邊可能過強；若日光連續數小時照在葉上，就向後移。[冬季照護指南](/zh-hant/guides/winter-houseplant-care/)介紹冷風與供暖。在 Lilora，提醒是請你檢查，並非命令澆水；可分別記錄「已檢查，不需澆水」或「已澆水」，讓寒冷月份較慢的乾燥速度反映在歷史紀錄中。延後提醒只會推遲提醒，不會新增照護紀錄。

## 常見問題

- **下葉變黃、介質仍濕：**再次澆水前檢查排水與根系。
- **褐色乾脆斑塊：**若在直射日光下，可能曬傷。
- **介殼蟲：**NC State 列出蕨類介殼蟲為常見害蟲；檢查莖與葉背。

[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)協助你觀察整體變化。

## 繁殖

NC State 列出莖插與壓條。插穗要有節點，最好帶氣生根。在溫暖明亮處以水或濕潤介質生根。需要修剪或換盆時選春季。[NC State Extension](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將龜背芋（亦稱 <span lang="en">cutleaf philodendron</span>）列為對貓狗有毒，原因是不溶性草酸鈣。所列症狀包括口腔刺激，口、舌與唇強烈灼痛及刺激，過度流口水、嘔吐與吞嚥困難。NC State 補充汁液可能刺激皮膚。寵物若咬食，請聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。比較其他植物可閱讀[植物與寵物指南](/zh-hant/guides/pet-safe-houseplants/)或[無毒植物圖鑑](/zh-hant/plants/#petNonToxic)。

## 常見問答

### 為什麼龜背芋沒有裂葉？

幼葉常是完整的。成熟、光線足夠且莖能攀爬後，通常才會形成裂口。

### 龜背芋是蔓綠絨嗎？

不是。有時以 <span lang="en">split-leaf philodendron</span> 販售，但它屬於 *Monstera*。

### 莖上長長的褐色根是什麼？

是氣生根。引導它們朝向支柱或介質，不要一次剪掉太多。

### 冬季要少澆水嗎？

通常間隔會變長，因為介質乾得慢。持續檢查上方四分之一至三分之一，不要改用另一個固定日程。
