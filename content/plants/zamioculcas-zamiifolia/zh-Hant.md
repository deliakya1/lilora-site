# 金錢樹照護

金錢樹是原產東非與南非的耐旱天南星科植物。粗厚的莖與地下根莖能儲水，因此室內主要風險是澆水過多。提供明亮間接光，介質完全乾透再澆，一年施肥一至兩次即可。它沒有出現在 ASPCA 植物清單中；NC State Extension 則將它列為有毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/zamioculcas-zamiifolia/)

## 光線

明亮間接光下表現最好，也耐陰，因此常被選作辦公室或較暗房間的植物。避免強烈直射日光：NC State 指出葉片可能灼傷變褐。低光下生長慢，也可能向窗戶傾斜。[NC State Extension](https://plants.ces.ncsu.edu/plants/zamioculcas-zamiifolia/)

使用[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)評估位置。

## 澆水前如何檢查

介質完全乾透才澆。檢查到盆的下半部；表面乾、根仍濕是常見誤判。NC State 建議冬季約每月一次、夏季約每月兩次，但前提都是土已乾，因此只能作粗略參考，不能當日程。[NC State Extension](https://plants.ces.ncsu.edu/plants/zamioculcas-zamiifolia/)

金錢樹不耐根長期泡水。徹底瀝乾並倒空托盤。[澆水指南](/zh-hant/guides/watering-houseplants/)介紹盆重檢查。

## 介質與花盆

使用排水良好的介質與有孔容器。根莖膨大可能把薄塑膠盆撐變形，這表示需要升一個尺寸，最好在春季。

## 濕度與溫度

NC State 的資料沒有特殊濕度要求，一般室內空氣適合多數植株。保持溫暖；若夏季把盆栽放戶外，溫度降到約 16 °C（60 °F）之前要搬回室內。[NC State Extension](https://plants.ces.ncsu.edu/plants/zamioculcas-zamiifolia/)

## 施肥

NC State 建議一年施一至兩次均衡室內植物液肥。多施肥無法彌補光線不足。[NC State Extension](https://plants.ces.ncsu.edu/plants/zamioculcas-zamiifolia/)

## 常見問題

- **莖變黃、基部軟爛：**常與介質過濕有關，檢查根莖。
- **褐色灼傷斑塊：**直射日光過多。
- **介殼蟲：**NC State 指出這是主要需要注意的害蟲。

不要只依一個症狀處理，先看[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)。

## 繁殖

換盆時分開根莖，或將單片小葉、葉柄插入微濕介質生根。葉插很慢，可能要數月才長新芽。[NC State Extension](https://plants.ces.ncsu.edu/plants/zamioculcas-zamiifolia/)

## 寵物與人

金錢樹沒有出現在 [ASPCA Animal Poison Control Center](https://www.aspca.org/) 的有毒與無毒植物清單中，查核日期為 2026 年 10 月 22 日。「未列出」不代表安全。NC State Extension 將它列為有毒，指出葉片含草酸鈣，大量食用可能引起嘔吐和腹瀉。請放在碰不到的地方。若寵物咬食，聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。

## 常見問答

### 它叫 Zamia 嗎？

有時以「Zamia」販售，但 *Zamia* 是不同的蘇鐵類植物屬。金錢樹是 *Zamioculcas zamiifolia*。

### 金錢樹能住在低光處嗎？

可以忍受，但長得慢。盡可能給它明亮間接光。

### 為什麼莖倒下？

先檢查光線，再看莖基部是否因介質過濕而變軟。
