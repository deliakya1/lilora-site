# 虎尾蘭照護

虎尾蘭長期以 *Sansevieria trifasciata* 販售，現在歸入 *Dracaena* 屬。它在厚實直立的葉片中儲水，耐很低的光線與乾燥空氣，但持續潮濕會腐爛。兩次澆水之間讓介質乾燥，冬季只需極少澆水。ASPCA 將它列為對貓狗有毒。[Kew, Plants of the World Online](https://powo.science.kew.org/taxon/urn:lsid:ipni.org:names:77164235-1)

## 光線

虎尾蘭能忍受很低的光線，適合走廊和離窗較遠的房間。不過，較明亮的光線，包括部分直射日光，能讓它生長得更穩定。從暗角移到向陽窗臺時要循序漸進，以免曬傷。[NC State Extension](https://plants.ces.ncsu.edu/plants/dracaena-trifasciata/)

[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)說明為何「低光」不等於「無光」。

## 澆水前如何檢查

春季到秋季，兩次澆水之間讓介質乾燥。檢查盆內深處，而非只看表面：整個根區都應摸起來乾燥，花盆也變輕。NC State 建議冬季可能只需每一至兩個月澆一次；這只是參考上限，仍要先檢查。[NC State Extension](https://plants.ces.ncsu.edu/plants/dracaena-trifasciata/)

澆水時要澆透，並徹底瀝乾。不要讓花盆泡在水裡。[澆水指南](/zh-hant/guides/watering-houseplants/)介紹如何判斷花盆重量。

## 介質與花盆

使用含砂礫、排水良好的介質，例如仙人掌與多肉用土，並選有排水孔的花盆。較重的赤陶盆有助避免高株翻倒。虎尾蘭能容忍稍擁擠的根系；根莖頂壓花盆或植株不穩時再換盆。

## 濕度與溫度

乾燥室內空氣不是問題。它能承受約 10 °C（50 °F）的短暫低溫，但不耐霜凍；冬季放在正常供暖的房間，遠離冰冷玻璃。[NC State Extension](https://plants.ces.ncsu.edu/plants/dracaena-trifasciata/)

## 施肥

生長慢，需肥量不高。生長季用室內植物肥少量施一至兩次就足夠；冬季不施肥。

## 季節照護

生長季兩次澆水之間應讓介質乾燥。NC State 指出，冬季可能每一至兩個月才需澆水；這反映乾燥速度慢，不是固定日程。仍應先確認整個根區已乾。它能忍受約 10 °C（50 °F）的涼爽房間與乾燥空氣，但過度澆水會爛根，寒冷又潮濕的介質風險最高。[NC State Extension](https://plants.ces.ncsu.edu/plants/dracaena-trifasciata/)

NC State 列出每天部分時段有 2–6 小時直射日光為理想環境；虎尾蘭也能適應陰暗位置，只是長得慢、乾得也慢。詳見[冬季照護指南](/zh-hant/guides/winter-houseplant-care/)。在 Lilora，提醒是請你檢查，並非命令澆水；可分別記錄「已檢查，不需澆水」或「已澆水」，讓寒冷月份較慢的乾燥速度反映在歷史紀錄中。延後提醒只會推遲提醒，不會新增照護紀錄。

## 常見問題

- **葉片基部柔軟、倒塌：**NC State 提醒，過度澆水會引起爛根。檢查根莖與根，組織堅實是好現象。
- **粉介殼蟲與葉蟎：**檢查葉片基部。
- **葉片皺縮：**可能是長期缺水，但大量澆水前仍應檢查根系。

調整照護前，先看[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)。

## 繁殖

換盆時可把過密的植株分開，每份保留根與葉。葉插也能生根，但斑葉品種常會長回全綠葉片。[NC State Extension](https://plants.ces.ncsu.edu/plants/dracaena-trifasciata/)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將虎尾蘭（英文俗名亦稱 <span lang="en">mother-in-law’s tongue</span>）列為對貓狗有毒，毒性成分是皂苷，症狀包括噁心、嘔吐與腹瀉。若寵物咬食，請聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。比較其他植物可看[植物與寵物指南](/zh-hant/guides/pet-safe-houseplants/)或[無毒植物圖鑑](/zh-hant/plants/#petNonToxic)。

## 常見問答

### 虎尾蘭多久澆一次水？

沒有固定次數。整個根區乾透才澆，可能需數週，冬季更少。

### 可以放在沒有窗戶的浴室嗎？

沒有光就不行。它耐低光，但仍需要窗戶或植物燈。

### 為什麼現在叫 Dracaena？

DNA 研究把 *Sansevieria* 歸入 *Dracaena*。邱園接受的名稱是 *Dracaena trifasciata*；照護方式不變。

### 虎尾蘭能接受直射日光嗎？

可以接受每天部分時段的直射光。NC State 指出 2–6 小時為理想，它也耐室內較暗的位置。
