# 蘆薈照護

蘆薈是原產阿拉伯半島的多肉植物。給它家中日照最充足的位置、含砂礫且排水良好的介質，以及有排水孔的花盆；兩次澆水之間要完全乾透，冬季只需極少量的水。澆水過多是最常見的死亡原因。ASPCA 將它列為對貓狗有毒的植物。[NC State Extension](https://plants.ces.ncsu.edu/plants/aloe-vera/)

## 光線

可種在全日照至半陰的位置。RHS 指出，蘆薈喜歡陽光充足、乾燥的環境，例如向陽窗臺。光線不足會讓葉片變淡、變薄、軟垂，蓮座狀葉叢也會拉長。從陰處移到強光處時，請花一至兩週逐步適應，避免曬傷。[NC State Extension](https://plants.ces.ncsu.edu/plants/aloe-vera/) · [RHS](https://www.rhs.org.uk/getmedia/d02059a1-4e2c-45c3-956b-da5cc90db7f1/Indoor-plants-resources.pdf)

[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)可協助你找出最明亮的位置。

## 澆水前如何檢查

兩次澆水之間，讓介質完全乾透，冬季再減少次數；RHS 的建議是幾乎不用澆。用木籤檢查到盆底，或提起花盆：乾燥的蘆薈盆會明顯變輕。確認乾透後澆透，讓多餘的水全部流走。[NC State Extension](https://plants.ces.ncsu.edu/plants/aloe-vera/) · [RHS](https://www.rhs.org.uk/getmedia/d02059a1-4e2c-45c3-956b-da5cc90db7f1/Indoor-plants-resources.pdf)

堅實飽滿的葉片通常表示仍有水分儲備。[澆水指南](/zh-hant/guides/watering-houseplants/)說明如何檢查濕度。

## 介質與花盆

使用適合多肉植物、排水極佳的介質，以及有數個排水孔的花盆。NC State 指出，陶盆最好，因為乾得較快，也更重、不易翻倒。[NC State Extension](https://plants.ces.ncsu.edu/plants/aloe-vera/)

## 濕度與溫度

RHS 指出，蘆薈不喜歡潮濕空氣，也無法承受結冰溫度。溫暖、明亮、通風的房間很合適；冬季要遠離可能結霜的冰冷玻璃。[RHS](https://www.rhs.org.uk/getmedia/d02059a1-4e2c-45c3-956b-da5cc90db7f1/Indoor-plants-resources.pdf)

## 施肥

RHS 建議生長季每月施一次液肥，冬季不施肥；在英國，生長季約為四月至九月。[RHS](https://www.rhs.org.uk/getmedia/d02059a1-4e2c-45c3-956b-da5cc90db7f1/Indoor-plants-resources.pdf)

## 常見問題

- **葉片柔軟、半透明或倒塌：**可能澆水過多或爛根，請檢查根系。
- **新生長變淡、拉長：**光線不足。
- **病蟲害：**NC State 列出粉介殼蟲與蚜蟲，也提到介殼蟲、葉斑病、蘆薈鏽病及煤煙病。

[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)提供更全面的排查方式。

## 繁殖

蘆薈會從基部長出側芽。換盆時分離帶有部分根系的側芽，讓切口乾燥，再種進乾燥的多肉介質，等待幾天才澆水。[NC State Extension](https://plants.ces.ncsu.edu/plants/aloe-vera/)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將蘆薈列為對貓狗有毒的植物，毒性成分包括皂苷與蒽醌，症狀包括嘔吐、嗜睡與腹瀉。NC State Extension 指出，乳汁可能刺激皮膚，誤食可能造成腹部絞痛與腹瀉。家中種植的蘆薈不是寵物的家庭療方。若寵物咬食，請聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。

## 常見問答

### 蘆薈多久澆一次水？

只在介質完全乾透後澆水，可能要隔數週；冬季更少。

### 為什麼蘆薈倒下來？

通常是光線不足或基部腐爛，兩者都要檢查。

### 蘆薈可以放在朝北窗臺嗎？

多數住宅的朝北窗臺光線不夠，請選最明亮的窗邊。
