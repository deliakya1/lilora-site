# 白鶴芋照護

白鶴芋是原產熱帶美洲與西太平洋的喜陰天南星科植物。避免直射日光，保持介質濕潤但不積水，提供溫暖、一定濕度並少量施肥。白鶴芋下垂時應檢查介質，不要自動澆水。ASPCA 列為對貓狗有毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/)

## 光線

偏好半陰至深陰；NC State 說明不可放直射日光下。RHS 建議明亮半陰處，避免向陽窗臺。比起暗角，較明亮位置通常開花較好。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/) · [RHS](https://www.rhs.org.uk/getmedia/d02059a1-4e2c-45c3-956b-da5cc90db7f1/Indoor-plants-resources.pdf)

[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)協助區分遮蔭與真正的黑暗。

## 澆水前如何檢查

保持介質濕潤但不積水，兩次澆水間可稍乾。白鶴芋比多肉乾得快，應經常檢查。表層剛乾、花盆變輕時澆透，也可由底部吸水；NC State 認為這個方法適合它，最後都應徹底瀝乾。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/)

缺水時會明顯萎蔫，但根過濕也會使葉下垂。加水前先摸介質。[澆水指南](/zh-hant/guides/watering-houseplants/)說明方法。

## 介質與花盆

NC State 建議富含有機質、微酸且排水良好的介質。根填滿花盆時換盆，建議時機為冬末。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/)

## 濕度與溫度

理想白天溫度約 20–29 °C（68–85 °F），夜間下降不宜超過約 5–6 °C（10 °F）。約 4–16 °C（40–60 °F）時生長大幅減慢，長期低於 4 °C（40 °F）會受損。RHS 指出，白鶴芋喜歡濕潤空氣，在非常乾燥的房間可能生長不良。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/) · [RHS](https://www.rhs.org.uk/getmedia/d02059a1-4e2c-45c3-956b-da5cc90db7f1/Indoor-plants-resources.pdf)

## 施肥

資料來源細節不同。NC State 建議用建議濃度的四分之一，並在施肥之間沖洗介質；RHS 建議每月依包裝用量施均衡液肥。共同原則是積極生長時溫和施肥，避免鹽分累積灼傷葉尖。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/)

## 季節照護

NC State 指出，約 4–16 °C（40–60 °F）的寒冷、有冷風環境會大幅減慢生長，長期低於 4 °C（40 °F）可損傷葉、莖和根。冬季放在溫暖房間，避開冷窗與門，持續檢查介質，不要固定某天澆水；生長較慢通常也乾得較慢。NC State 建議需要時在二月或三月換盆。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/)

供暖房間常乾燥，NC State 將低濕度與褐色葉尖連結。夏季避免直射日光，它也可能讓葉尖變褐。詳見[冬季照護指南](/zh-hant/guides/winter-houseplant-care/)與[濕度指南](/zh-hant/guides/houseplant-humidity/)。在 Lilora，提醒是請你檢查，並非命令澆水；可分別記錄「已檢查，不需澆水」或「已澆水」，讓寒冷月份較慢的乾燥速度反映在歷史紀錄中。延後提醒只會推遲提醒，不會新增照護紀錄。

## 常見問題

- **葉尖變褐：**NC State 列出直射日光、缺水、低濕度與肥料鹽分等可能原因。
- **粉介殼蟲：**最常見的室內害蟲；以濕布擦拭葉片。
- **不開花：**常因光線不足。

[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)介紹其他葉片變化。

## 繁殖

換盆時分開擁擠的叢株，每份保留根與數片葉。[NC State Extension](https://plants.ces.ncsu.edu/plants/spathiphyllum/)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將白鶴芋列為對貓狗有毒，原因是不溶性草酸鈣。所列症狀包括口腔刺激，口、舌與唇灼痛及刺激，過度流口水、嘔吐與吞嚥困難。雖然英文俗名是 <span lang="en">peace lily</span>，它並非真正的百合屬（*Lilium*）。寵物若咬食，請聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。比較其他植物可看[植物與寵物指南](/zh-hant/guides/pet-safe-houseplants/)或[無毒植物圖鑑](/zh-hant/plants/#petNonToxic)。

## 常見問答

### 為什麼白鶴芋下垂？

可能缺水，也可能根過濕。先檢查介質。

### 白色的「花」是花瓣嗎？

它是佛焰苞，是包圍花穗的特化葉片。

### 可以在低光下生長嗎？

耐陰，但更多間接光通常會使開花更好。

### 何時換盆？

根填滿花盆時。NC State 建議二月或三月，盆徑只小幅增加。
