# 心葉蔓綠絨照護

心葉蔓綠絨是原產墨西哥及熱帶美洲的攀爬性天南星科植物，葉片亮澤、呈心形。喜歡中等間接光，也耐低光；生長期喜歡微濕介質，扦插容易生根。它常被誤認為黃金葛，後者的葉較厚，常有斑紋。ASPCA 將它列為對貓狗有毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/philodendron-hederaceum/)

## 光線

偏好中等光線，也能在很低光下存活很久。Missouri Botanical Garden 建議明亮間接光、避免全日照；過暗時莖會細長，葉距拉大。[NC State Extension](https://plants.ces.ncsu.edu/plants/philodendron-hederaceum/) · [Missouri Botanical Garden](https://www.missouribotanicalgarden.org/PlantFinder/PlantFinderDetails.aspx?kempercode=b611)

詳見[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)。

## 澆水前如何檢查

生長期間保持介質微濕，冬季減少澆水。先檢查上方幾公分：摸起來乾就澆透瀝乾，仍濕則等待。介質過濕可能導致爛根。[NC State Extension](https://plants.ces.ncsu.edu/plants/philodendron-hederaceum/)

[澆水指南](/zh-hant/guides/watering-houseplants/)介紹其他水分線索。

## 介質與花盆

Missouri Botanical Garden 建議以土壤為基礎的盆栽介質。使用有排水孔的盆，可用吊籃讓枝條下垂，或給水苔柱攀爬。[Missouri Botanical Garden](https://www.missouribotanicalgarden.org/PlantFinder/PlantFinderDetails.aspx?kempercode=b611)

## 濕度與溫度

喜歡一般室內溫度。耐乾燥空氣，但偏好中等濕度。遠離冷窗與暖氣出風口。[NC State Extension](https://plants.ces.ncsu.edu/plants/philodendron-hederaceum/)

## 施肥

春夏依標籤用量施均衡室內植物肥，冬季停肥。光線良好卻長出蒼白新葉，可能需要施肥，但應先檢查根與水分。

## 常見問題

- **莖徒長、葉片小：**光線不足。摘心可讓下垂枝條長得更茂密。
- **葉斑與爛根：**常與介質過濕有關。
- **蟲害：**蚜蟲、葉蟎、粉介殼蟲與介殼蟲。

調整照護前請讀[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)。

## 繁殖

春季取至少帶一個節點的莖段，在水中或濕潤介質中生根。[NC State Extension](https://plants.ces.ncsu.edu/plants/philodendron-hederaceum/) · [Missouri Botanical Garden](https://www.missouribotanicalgarden.org/PlantFinder/PlantFinderDetails.aspx?kempercode=b611)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將心葉蔓綠絨列為對貓狗有毒，原因是不溶性草酸鈣結晶。所列症狀包括口腔刺激，口、舌與唇疼痛腫脹，大量流口水、嘔吐與吞嚥困難。NC State Extension 指出汁液可刺激皮膚。若寵物咬食，請聯絡獸醫或動物毒物諮詢服務。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。

## 常見問答

### 和黃金葛有什麼不同？

心葉蔓綠絨的葉更薄、柔軟，心形更明顯；黃金葛葉片較厚，常有條紋。

### 一定需要水苔柱嗎？

不需要，它很適合垂吊。有支柱則可攀爬，通常會長出更大的葉。

### 為什麼莖又長又禿？

通常是低光。移近明亮間接光並摘心。
