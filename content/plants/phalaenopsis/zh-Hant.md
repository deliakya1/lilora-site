# 蝴蝶蘭照護

蝴蝶蘭（*Phalaenopsis*）生長在亞洲熱帶、亞熱帶及澳洲東北部的樹上。在室內需要明亮間接光、樹皮基質的蘭花介質、能完全瀝乾的澆水方式、溫暖與良好濕度。一段較涼的時期有助許多植株抽出新花梗。ASPCA 列為對貓狗無毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/phalaenopsis/)

## 光線

提供明亮間接光。NC State 建議東向窗臺，或遮蔭充分的西窗、南窗。RHS 建議冬季給予明亮光線促進開花，夏季避免會曬傷葉片的直射日光。[NC State Extension](https://plants.ces.ncsu.edu/plants/phalaenopsis/) · [RHS](https://www.rhs.org.uk/plants/phalaenopsis/growing-guide)

深綠軟垂的葉片可能表示光太少；偏黃或灼傷可能表示太多。詳見[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)。

## 澆水前如何檢查

樹皮開始乾燥時澆水。透明盆中呈銀色的根與較輕的花盆是有用線索；綠色飽滿的根表示近期已澆過。早晨使用微溫水，最好是雨水，可由上方澆或將盆放入水碗，之後徹底瀝乾。切勿長期泡水，也不要讓根完全乾死。[NC State Extension](https://plants.ces.ncsu.edu/plants/phalaenopsis/) · [RHS](https://www.rhs.org.uk/plants/phalaenopsis/growing-guide)

成熟植株在生長季可能約每週需水，冬季較少，但應以樹皮狀態決定。[澆水指南](/zh-hant/guides/watering-houseplants/)說明原因。

## 介質與花盆

使用專門配製的樹皮基質蘭花介質。RHS 警告，以壤土為基礎或一般多用途培養土會使蝴蝶蘭死亡。約每兩年，或樹皮分解時換盆；健康根應飽滿、堅實、銀白。[RHS](https://www.rhs.org.uk/plants/phalaenopsis/growing-guide)

## 濕度與溫度

RHS 提供的理想範圍為白天 19–30 °C（66–86 °F）、夜間 16–19 °C（61–66 °F），最低 16 °C（60 °F）。避開暖氣與冷風。偏好高濕度；盆下放寬大的濕礫石托盤有幫助。[RHS](https://www.rhs.org.uk/plants/phalaenopsis/growing-guide)

## 施肥

生長季用蘭花肥少量規律施用，每第四次澆水只用清水沖洗鹽分。冬季很少施肥，或完全不施。[RHS](https://www.rhs.org.uk/plants/phalaenopsis/growing-guide)

## 常見問題

- **沒有新花：**NC State 指出，許多大花雜交種需要秋季約一週、夜間約 13 °C（55 °F）的環境；RHS 建議放在低約 5 °C 的位置一個月。
- **落蕾：**溫度、水分或位置突然改變。
- **葉片皺縮：**缺水，或介質過濕導致根受損。請檢查根。
- **蟲害：**粉介殼蟲與介殼蟲。

## 繁殖

家庭繁殖不常見。有些植株會在花梗上形成小苗 keiki，長出幾公分的根後可分盆。

開花後，RHS 建議在舊花梗第二節上方剪斷；若已乾枯，就從基部剪除。[RHS](https://www.rhs.org.uk/plants/phalaenopsis/growing-guide)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將 *Phalaenopsis* 蘭花列為對貓狗無毒，NC State Extension 也做出相同標示。無毒不代表可以任意吃：咀嚼仍可能造成腸胃不適，經處理或剛施肥的植株也有其他風險。寵物若不舒服，請聯絡獸醫。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。

## 常見問答

### 應該用冰塊澆蘭花嗎？

本文資料來源建議使用微溫水並充分瀝乾。

### 為什麼根長到盆外？

這種附生植物長氣生根很正常，健康的根請保留。

### 開花後要剪花梗嗎？

在第二節上方剪；若花梗變淡、乾燥，就從基部剪。
