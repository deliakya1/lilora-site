# 吊蘭照護

吊蘭原產熱帶及南部非洲，是適應力強、長得快的室內植物。提供沒有直射日光的中等光線，生長期間讓介質保持微濕；若自來水使葉尖變褐，可改用雨水或過濾水。它會在長莖上長出小植株，很容易生根。ASPCA 將它列為對貓狗無毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/chlorophytum-comosum/)

## 光線

吊蘭喜歡中等光線，也耐陰，但不喜歡直射日光。離明亮窗戶稍遠處，或光線充足的層架都很適合。斑葉品種在充足的間接光下，條紋較能維持。[NC State Extension](https://plants.ces.ncsu.edu/plants/chlorophytum-comosum/)

詳見[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)。

## 澆水前如何檢查

吊蘭在濕潤土壤中長得最好，也能忍受短暫乾燥。生長期間，等介質表面乾燥再澆，冬季減少澆水。粗厚的白色根能儲水，因此稍乾的盆比持續濕透的盆風險小。[NC State Extension](https://plants.ces.ncsu.edu/plants/chlorophytum-comosum/)

[澆水指南](/zh-hant/guides/watering-houseplants/)說明如何結合觸摸與花盆重量判斷。

## 介質與花盆

可用以壤土為基礎或一般室內植物介質，重點是排水良好。肉質根很快就會填滿花盆，甚至把植株頂起；根擠滿表面時就換盆或分株。

## 濕度與溫度

中等濕度已足夠；空氣很乾時，加濕器或濕卵石托盤能提供幫助。溫度應保持在 7 °C（45 °F）以上。[NC State Extension](https://plants.ces.ncsu.edu/plants/chlorophytum-comosum/)

## 施肥

春夏少量施肥。NC State 提醒，施肥過多會減少小植株的形成。[NC State Extension](https://plants.ces.ncsu.edu/plants/chlorophytum-comosum/)

## 季節照護

NC State 建議冬季減少澆水，並保持 7 °C（45 °F）以上。吊蘭喜歡均勻濕潤的介質，但也耐短期乾燥；較冷月份應先檢查再澆，讓表層多乾一點。[NC State Extension](https://plants.ces.ncsu.edu/plants/chlorophytum-comosum/)

短日照還有一個好處：NC State 指出，連續至少三週每天受光少於 12 小時，會促使走莖形成，因此秋季之後常出現小植株。夏季仍應避免它無法承受的直射日光。詳見[冬季照護指南](/zh-hant/guides/winter-houseplant-care/)。在 Lilora，提醒是請你檢查，並非命令澆水；可分別記錄「已檢查，不需澆水」或「已澆水」，讓較冷月份乾得較慢的情況留在自己的歷史紀錄中。延後提醒只會推遲提醒，不會新增照護紀錄。

## 常見問題

- **葉尖變褐：**NC State 指出，可能與自來水中的氯和氟有關。試用雨水或過濾水，並避免肥料累積。
- **葉片蒼白軟垂，介質仍濕：**檢查排水。
- **沒有小植株：**通常經過數週短日照及不被打斷的長夜後才會長出走莖；施肥過重也會減少形成。

更全面的排查請見[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)。

## 繁殖

吊蘭可用小植株或分株輕鬆繁殖。小植株還連在母株上時，可將它固定在濕潤介質上，也可放水中生根；長根後再剪斷走莖。NC State 指出，連續至少三週每天受光少於 12 小時，會形成走莖。[NC State Extension](https://plants.ces.ncsu.edu/plants/chlorophytum-comosum/)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將吊蘭列為對貓狗無毒，NC State Extension 也做出相同標示。無毒不代表可以任意吃：咀嚼植物仍可能造成腸胃不適，垂下的葉片也常吸引貓。若貓會咬葉，請掛在牠碰不到的地方。寵物若不舒服，請聯絡獸醫。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。比較其他植物可閱讀[植物與寵物指南](/zh-hant/guides/pet-safe-houseplants/)，或查看[圖鑑中的無毒植物](/zh-hant/plants/#petNonToxic)。

## 常見問答

### 為什麼吊蘭葉尖變褐？

自來水中的物質、乾燥空氣和肥料累積都是常見原因。每次只調整一件事。

### 何時剪下小植株？

長出幾公分的根後即可，也可以留著，讓吊盆看起來更茂盛。

### 吊蘭對貓安全嗎？

ASPCA 列為對貓狗無毒，但仍應避免咬食。

### 為什麼吊蘭沒有長小植株？

走莖通常在連續數週每天日照少於 12 小時後形成。NC State 指出，施肥過多也會減少形成。
