# 竹芋照護

市售多數俗稱 <span lang="en">calathea</span> 的竹芋，如今屬於 *Goeppertia*；許多物種在遺傳研究後從 *Calathea* 移入此屬。這些中南美洲林下植物需要中至低度的間接光、均勻濕潤但不積水的介質、軟水、穩定溫暖和高濕度。它們比黃金葛更難容忍照護失誤。ASPCA 將竹芋列為對貓狗無毒。[NC State Extension](https://plants.ces.ncsu.edu/plants/goeppertia/)

## 光線

給予中至低度間接光。直射日光會灼傷葉片，讓花紋褪色。明亮房間中避開光束的位置，或朝北窗邊，通常合適。葉片夜間向上摺起、白天展開，因此這一類植物有「祈禱植物」的俗稱。[NC State Extension](https://plants.ces.ncsu.edu/plants/goeppertia/)

使用[室內光線指南](/zh-hant/guides/indoor-plant-light-guide/)評估位置。

## 澆水前如何檢查

保持介質濕潤、排水良好，但不要濕透積水。經常檢查表面，頂層剛開始乾就澆，不要等整盆乾透。NC State 建議使用蒸餾水或雨水，因為自來水可能損傷葉片。[NC State Extension](https://plants.ces.ncsu.edu/plants/goeppertia/)

捲葉或黃葉可能表示缺水；葉片下垂伴隨莖腐爛則可能是水太多或太冷。採取行動前先檢查介質。[澆水指南](/zh-hant/guides/watering-houseplants/)說明方法。

## 介質與花盆

使用肥沃且排水順暢的介質，搭配有孔花盆。NC State 建議每年到每兩年換盆一次，最好在春季。[NC State Extension](https://plants.ces.ncsu.edu/plants/goeppertia/)

## 濕度與溫度

維持約 18–24 °C（65–75 °F），避開驟變與冷風。可用濕卵石托盤提高濕度，也可放在自然潮濕的明亮浴室或廚房。[NC State Extension](https://plants.ces.ncsu.edu/plants/goeppertia/)

## 施肥

春夏少量施用稀釋的室內植物肥，偶爾以不含肥料的軟水沖洗介質。鹽分累積與硬水都會在葉片留下損傷。

## 常見問題

- **葉緣褐色、乾脆：**常與低濕度或自來水中的物質有關。
- **灼傷、褪色斑塊：**直射日光。
- **莖腐爛、葉片下垂：**水太多或太冷。
- **病蟲害：**葉蟎、粉介殼蟲、介殼蟲與蚜蟲。潮濕且不流通的空氣可能引發灰黴；移除受害部分並改善通風。

[黃葉檢查指南](/zh-hant/guides/yellow-houseplant-leaves/)協助比較多個線索。

## 繁殖

春季換盆時分株，每份保留自己的根與數片葉。適應期間保持溫暖和高濕度。[NC State Extension](https://plants.ces.ncsu.edu/plants/goeppertia/)

## 寵物與人

[ASPCA Animal Poison Control Center](https://www.aspca.org/) 將 *Calathea* 屬列為對貓狗無毒，相關的祈禱植物 *Maranta* 也列為無毒。無毒不代表可以任意吃：咀嚼仍可能造成腸胃不適，農藥或肥料殘留則是另一種風險。寵物若不舒服，請聯絡獸醫。人員誤食時請聯絡當地毒物資訊中心；這與動物的獸醫服務不同。以上為一般資訊，並非獸醫或醫療建議。

## 常見問答

### 為什麼竹芋葉片會動？

傍晚向上摺起、早晨放下，是正常的日常運動。

### 是 Calathea 還是 Goeppertia？

許多常見物種現在的學名屬於 *Goeppertia*，商店仍常用 <span lang="en">calathea</span>。

### 一定要用蒸餾水嗎？

NC State 建議蒸餾水或雨水，因為自來水可能損傷葉片。
