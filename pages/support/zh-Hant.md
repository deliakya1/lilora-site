<h2 id="faq">常見問題</h2><div class="faq-list"><details class="faq-item" id="language"><summary><h3>如何切換語言？</h3></summary><div class="faq-answer"><p>開啟英文選單 <span lang="en">Settings → Language</span>（設定 → 語言），選擇 <span lang="en">English</span> 或 <span lang="tr">Türkçe</span>。選擇會儲存在此裝置。選取 <span lang="en">Use phone language</span>（使用手機語言）可恢復自動選擇：手機主要語言為土耳其文時使用土耳其文，否則使用英文。</p></div></details><details class="faq-item" id="storage"><summary><h3>植物資料存在哪裡？</h3></summary><div class="faq-answer"><p>沒有帳號時，資料只儲存在此裝置。刪除應用程式也會刪除資料。</p>
<p>登入並建立或加入家庭群組後，群組中的植物、照護歷程與照片會存在線上，並與成員共享。登出會移除此裝置上的家庭群組快取，但不會刪除家庭群組。</p></div></details><details class="faq-item" id="delete-account"><summary><h3>如何刪除帳號？</h3></summary><div class="faq-answer"><p>使用英文選單 <span lang="en">Settings → Delete account</span>（設定 → 刪除帳號）。確認前，應用程式會說明對家庭群組的影響。輸入 <span lang="en">DELETE</span> 確認。其他成員保留共用紀錄，您的署名改為前成員；若您是唯一成員，家庭群組會關閉，資料也會移除。只刪除應用程式不會刪除線上帳號。刪除帳號不會取消 App Store 訂閱，請到 App Store 帳號設定取消。</p></div></details><details class="faq-item" id="care-outcomes"><summary><h3>為什麼 Lilora 提醒「檢查」，而不是「澆水」？</h3></summary><div class="faq-answer"><p>到了檢查時間，應先觀察植物與介質。只有介質需要水時才澆，然後選擇英文項目 <span lang="en">Watered</span>（已澆水）；不需要水時，選擇 <span lang="en">Checked, no water needed</span>（已檢查，不需澆水）。</p></div></details><details class="faq-item" id="reminders"><summary><h3>我收不到提醒。</h3></summary><div class="faq-answer"><p>在應用程式的英文 <span lang="en">Today</span>（今日）或 <span lang="en">Settings</span>（設定）開啟提醒，並確認 iOS「設定 → 通知」已允許 Lilora 通知。檢查或澆水提醒會在到期當天的當地時間 9:00 送達。</p></div></details><details class="faq-item" id="correct-care"><summary><h3>可以更正照護紀錄嗎？</h3></summary><div class="faq-answer"><p>開啟植物，點選英文 <span lang="en">History</span>（歷程）中的項目，再選 <span lang="en">Correct this entry</span>（更正此項）或 <span lang="en">Remove entry</span>（移除此項）。歷程中仍可看到先前的內容。</p></div></details><details class="faq-item" id="remove-plant"><summary><h3>如何移除植物？</h3></summary><div class="faq-answer"><p>開啟植物並選擇英文 <span lang="en">Archive</span>（封存）。封存植物保留歷程，可從 <span lang="en">My plants → Archived plants</span>（我的植物 → 已封存植物）還原。<span lang="en">Delete plant</span>（刪除植物）會永久移除植物、照片及所有照護歷程，包括尚未傳送的項目。在共用家庭群組中，所有成員都會失去該植物。此操作無法復原。</p></div></details><details class="faq-item" id="photo-identification"><summary><h3>照片辨識如何運作？</h3></summary><div class="faq-answer"><p>登入後，開啟英文 <span lang="en">Add plant</span>（新增植物）或尚未填寫種類的植物，點選 <span lang="en">Add a plant with AI</span>（用 AI 新增植物）。Lilora 會顯示幾個 Pl@ntNet 候選結果；您選定前不會儲存。隨時都能免費手動輸入植物種類。前 3 次辨識免費。只有取得候選結果時才會扣除一次；沒有匹配、錯誤或逾時都不扣次數，同一張照片重試也不會重複計費。</p></div></details><details class="faq-item" id="more-identifications"><summary><h3>如何取得更多辨識次數？</h3></summary><div class="faq-answer"><p>英文選單 <span lang="en">Settings → Usage &amp; purchases</span>（設定 → 用量與購買，畫面標題為 <span lang="en">Identifications</span>）提供 10 次辨識組合，以及每月 30 次的 <span lang="en">Lilora Plus Monthly</span> 訂閱。App Store 會以您的貨幣顯示價格。每月次數於當月結束時到期，不會累計至下個月。</p></div></details><details class="faq-item" id="restore-purchases"><summary><h3>我在另一部裝置買過辨識次數，或重新安裝了應用程式。</h3></summary><div class="faq-answer"><p>登入同一個 Lilora 帳號，再點選英文選單 <span lang="en">Settings → Usage &amp; purchases → Restore purchases</span>（設定 → 用量與購買 → 回復購買項目）。購買項目屬於當初購買的 Lilora 帳號。</p></div></details><details class="faq-item" id="cancel-subscription"><summary><h3>如何取消 Lilora Plus 或申請退款？</h3></summary><div class="faq-answer"><p>在英文選單 <span lang="en">Settings → Usage &amp; purchases</span>（設定 → 用量與購買）點選 <span lang="en">Manage subscription</span>（管理訂閱），或開啟 App Store 帳號設定。退款由 Apple 處理，請前往 <a href="https://reportaproblem.apple.com">reportaproblem.apple.com</a>.</p></div></details><details class="faq-item" id="privacy-requests"><summary><h3>隱私權請求</h3></summary><div class="faq-answer"><p>如需行使存取、更正、刪除資料或其他隱私權利，請參閱 <a href="/zh-hant/privacy/#rights">您的隱私權利</a>. 政策中說明 KVKK 與 GDPR 的請求管道及期限。</p></div></details></div></article>
